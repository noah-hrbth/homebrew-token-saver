# homebrew-token-saver

Homebrew tap for [token-saver](https://github.com/noah-hrbth/token-saver), a transparent CLI proxy that compresses verbose command output for LLM agents.

## Install

```sh
brew tap noah-hrbth/token-saver
brew install token-saver
```

See the [main repo](https://github.com/noah-hrbth/token-saver) for setup instructions.
